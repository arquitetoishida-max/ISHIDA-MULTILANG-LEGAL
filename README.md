# ISHIDA MULTILANG — Site jurídico

Site estático para GitHub Pages. Arquivos HTML na raiz do repositório.

## Antes de publicar oficialmente
1. Substituir Gabriel Noboru Ishida e ishida.ok@gmail.com em todos os arquivos HTML.
2. Conferir a Política de Privacidade com o comportamento real da última versão do APK.
3. Gerar e incorporar licenças e avisos dos componentes de terceiros realmente presentes no APK.
4. Conferir o fluxo técnico de exclusão de conta e o e-mail público, antes de usar o link no Google Play Console.
5. Revisar os textos jurídicos antes de disponibilizar licenças pagas.

Configuração: Settings → Pages → Deploy from a branch → main → /(root).
