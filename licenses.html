Licenças e créditos

Versão preliminar 1.0 · 28 de outubro de 2026

O ISHIDA MULTILANG utiliza componentes autorais próprios e poderá incorporar bibliotecas de código, fontes e conjuntos de dados de terceiros.

Bibliotecas editoriais

O sistema editorial VCU14, sua organização e os textos de vocabulário revisados para o projeto são tratados como conteúdo editorial do ISHIDA MULTILANG, respeitados os direitos comprovadamente aplicáveis a materiais eventualmente incorporados de outras fontes.

Componentes de terceiros

Os componentes de software utilizados pelo aplicativo, incluindo Flutter, SDKs de autenticação, fontes, bibliotecas de escrita como KanjiVG ou Hanzi Writer (quando efetivamente incorporadas) e quaisquer dados licenciados, conservam os avisos e as obrigações de suas respectivas licenças.
